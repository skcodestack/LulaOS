# SMP 多核支持实现

## 设计思路

SMP 启动流程：
1. BSP 将 trampoline 代码复制到物理 0x1000（SIPI 目标页）
2. BSP 向每个 AP 发送 INIT-SIPI-SIPI 序列
3. AP 在实模式启动 → 切换保护模式 → 开启分页 → 调用 `start_secondary()`
4. AP 初始化自己的 Local APIC / Timer，进入 idle 循环
5. 调度器改为 per-CPU：每个核心独立的 `current` 和 runqueue

---

## Task 1: 添加 SMP 头文件 `includes/arch/x86/smp.h`

新建文件，定义：
```c
#define SMP_TRAMPOLINE_PHYS  0x1000   // SIPI 目标物理地址
#define SMP_TRAMPOLINE_VECTOR 0x01    // SIPI vector = 物理页号
#define SMP_MAX_CPUS         NR_CPUS  // 32

extern int smp_num_cpus;              // 在线 CPU 数量
extern int cpu_online_map;            // 在线 CPU 位图

int  smp_processor_id(void);          // 读 LAPIC ID → 查 cpu_number[]
void smp_init(void);                  // BSP 调用：启动所有 AP
void start_secondary(void);           // AP 的 C 入口
```

## Task 2: 修改 `includes/kernel/sched.h` - Per-CPU 调度器

将单 CPU 变量改为 per-CPU 数组：
- `extern struct task_struct *current_p;` → `extern struct task_struct *current_p[NR_CPUS];`
- `#define current (*current_p)` → `#define current (*current_p[smp_processor_id()])`
- `sched_init()` 中初始化 `current_p[0] = &init_task`，其余为 `idle` 任务

`scheduler_tick()` 中：
- `runqueues[0]` → `runqueues[smp_processor_id()]`
- `current` 自动通过宏解析到正确的 per-CPU 变量

## Task 3: 修改 `kernel/sched.c` - Per-CPU 实现

- `current_p` 从单变量改为数组 `struct task_struct *current_p[NR_CPUS]`
- `sched_init()` 中为 cpu 0 设置 `current_p[0] = &init_task`，`runqueues[0].idle = &init_task`
- `schedule()` 中 `runqueue_t *rq = &runqueues[smp_processor_id()]`
- `scheduler_tick()` 中同样使用 `smp_processor_id()` 索引

## Task 4: 添加 AP Trampoline `arch/x86/entry.S`

在 `entry.S` 末尾添加 SMP trampoline 代码块：

```asm
ENTRY(smp_trampoline_start)
    .code16
    cli
    xorw %ax, %ax
    movw %ax, %ds
    // 保存 SIPI 参数（在 0x1000 页内的固定偏移）
    movl $0x1000+0x100, %esi  // 栈地址
    movl $0x1000+0x104, %edi  // start_secondary 入口

    lgdtl %ds:0x1000+0x200    // 临时 GDT 指针
    movl %cr0, %eax
    orb  $1, %al
    movl %eax, %cr0           // 进入保护模式
    ljmpl $0x08, $0x1000+0x50 // 跳转到 32 位代码

    .code32
    // 加载 GDT/IDT（使用 BSP 的全局表）
    lgdt _gdt_pointer
    lidt _idt_pointer

    // 开启分页
    movl $swapper_pg_dir, %eax
    movl %eax, %cr3
    movl %cr0, %eax
    orl  $0x80000000, %eax
    movl %eax, %cr0

    // 远跳转切换到 __KERNEL_CS
    ljmp $0x08, $1f
1:  movw $0x10, %ax
    movw %ax, %ds; movw %ax, %es; movw %ax, %fs
    movw %ax, %gs; movw %ax, %ss

    // 切换到 BSP 分配的 AP 内核栈
    movl 0x1000+0x100, %esp

    // 调用 AP C 入口
    call start_secondary
    // 不应返回
2:  hlt; jmp 2b
ENTRY(smp_trampoline_end)
```

trampoline 内嵌临时 GDT（6 个条目：null + 4 段 + padding），以及 GDTR 指针结构。

## Task 5: 修改 `linker.lds` - trampoline 段位置

在 `.text` 段之前（或内）添加 `.trampoline` 段，保证 trampoline 代码在可访问的内核虚拟地址中（可通过 `__va()` 换算物理地址）：

```
.trampoline BLOCK(4K): AT(ADDR(.trampoline) - 0xC0000000)
{
    _trampoline_start = .;
    *(.trampoline)
    _trampoline_end = .;
}
```

## Task 6: 新建 `arch/x86/kernel/smp.c` - SMP 初始化

```c
int smp_num_cpus = 1;
int cpu_online_map = 1;   // BSP (cpu 0) 始终在线
static int cpu_number[ACPI_MAX_LAPIC]; // APIC ID → 逻辑 CPU 号

int smp_processor_id(void) {
    unsigned int id = GET_APIC_ID(apic_read(APIC_ID));
    return cpu_number[id];
}

void smp_init(void) {
    // 1. 复制 trampoline 到物理 0x1000
    memcpy(__va(SMP_TRAMPOLINE_PHYS),
           _trampoline_start,
           _trampoline_end - _trampoline_start);

    // 2. 写入 GDT/IDT 指针到 trampoline 页内偏移 0x200
    // 3. 写入 start_secondary 地址到偏移 0x104

    // 4. 遍历 acpi_context.lapics[]，跳过 BSP
    for (i = 0; i < acpi_context.lapic_count; i++) {
        if (lapic.id == bsp_apic_id) continue;
        // 分配 AP 内核栈（__alloc_pages）
        // 写栈地址到 trampoline 偏移 0x100
        // 调用 send_startup_ipi(lapic.id, SMP_TRAMPOLINE_VECTOR)
        // 等待 AP 上线（轮询 cpu_online_map 或超时）
        smp_num_cpus++;
    }
}

void start_secondary(void) {
    // 1. 加载本 CPU 的 GDT/IDT（已共享，可跳过）
    // 2. 初始化 Local APIC（remapping_apic + enable + SPIV + Timer）
    local_apic_init_ap();
    // 3. 开中断
    sti();
    // 4. 标记在线
    cpu_online_map |= (1 << smp_processor_id());
    // 5. 进入 idle 循环
    for (;;) safe_halt();
}
```

## Task 7: 修改 `arch/x86/kernel/apic.c` - AP 的 Local APIC 初始化

新增 `local_apic_init_ap()` 函数，供 AP 调用：
- `remapping_apic()` - 映射 LAPIC 到 fixmap
- `enable_hardware_apic()` - 使能 MSR
- `apic_setup_lvts()` - 配置 LVT
- `calibrate_apic_timer()` - 校准 Timer（每个 AP 独立校准）
- 配置 SPIV（使能 APIC）

与 BSP 的 `local_apic_init()` 逻辑基本相同，但不需要 `disable_8259_pic()`（已由 BSP 完成）和 `io_apic_init()`。

## Task 8: 修改 `kernel/kernel.c` - 集成 SMP 初始化

```c
#include <arch/x86/smp.h>

asmlinkage void _kernel_main() {
    // ... 现有初始化 ...
    sched_init();
    mm_init();
    kmem_cache_init();

    smp_init();  // 启动所有 AP

    sti();
    for (;;) safe_halt();
}
```

`smp_init()` 放在 `kmem_cache_init()` 之后（AP 栈需要 `__alloc_pages`）。
